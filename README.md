# AUT Swap App

University Swap — AUT Campus Marketplace (macOS)

## Requirements

- **macOS 13.0 (Ventura)** or later
- Xcode 14+

## Run

1. Open `AUT Swap App.xcodeproj` in Xcode
2. Select **My Mac** as the run destination
3. Press **Cmd + R**

## Features

- AUT email login (@aut.ac.nz / @autuni.ac.nz)
- Home browse with 4-column product grid
- Category & campus filtering
- Shopping cart (offline payment)
- Listing detail view
